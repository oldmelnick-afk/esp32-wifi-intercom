# Коробка комната 3: 3-й этаж, комната 1 (`ROOM 3`, `3F-A`)

![Схема проводов коробки комната 3](diagrams/third-floor-room3-assistant.svg)

Это схема **имеющейся 30-контактной ESP32 DevKit V1.302**, микрофона
ICS-43434 и усилителя MAX98357A. Третья коробка собирается **без LCD** из
окружения `screenless`. Номера контактов ниже даны для вида **со стороны
пайки при USB слева**; верхний и нижний ряды считаются слева направо.
Надписи на конкретной плате следует сверить до пайки.

| Цепь | Контакт ESP32 | Второй конец |
|---|---|---|
| Питание +5 В | нижний 01, `VIN/5V` | центр проверенного гнезда DC; также `VIN` усилителя |
| Общий минус | нижний 02, `GND`; верхний 02 — та же земля | минус DC, усилителя, микрофона, светодиода и кнопок |
| Питание микрофона | верхний 01, `3V3` | `3V` микрофона; **не 5 В** |
| Индикатор | верхний 04, `D2` | резистор 220–470 Ом → анод LED; катод → GND |
| Большая «Всем» | нижний 10, `D32` | нормально разомкнутая кнопка → GND |
| К1 → 1-й этаж | верхний 09, `D18` | кнопка → GND |
| К2 → 2-й этаж | верхний 10, `D19` | кнопка → GND |
| К3 → 3F-B | верхний 11, `D21` | кнопка → GND |
| К4 → 4-й этаж | нижний 09, `D33` | кнопка → GND |
| **Отдельная «ИИ»** | **верхний 07, `TX2/D17`** | **нормально разомкнутая кнопка → GND** |
| MIC `BCLK` | нижний 05, `D14` | микрофон `BCLK` |
| MIC `LRCL` | нижний 06, `D27` | микрофон `LRCL` |
| MIC `DOUT` | нижний 12, `D34` | микрофон `DOUT` |
| AMP `LRC` | нижний 08, `D25` | усилитель `LRC` |
| AMP `BCLK` | нижний 07, `D26` | усилитель `BCLK` |
| AMP `DIN` | верхний 14, `D22` | усилитель `DIN` |

У микрофона `SEL` и `GND` идут на **общий GND**. У усилителя `GND` идёт на
общий GND, `VIN` — на проверенные +5 В. `GAIN` и `SD` оставляются в штатном
состоянии модуля, как у первых коробок. Динамик соединяется **только** с
`SPK+` и `SPK−` усилителя; ни один из его проводов не идёт на GND.

Для кнопки с четырьмя ножками сначала прозвонить пары: две ножки с одной
стороны уже могут быть соединены между собой. Использовать контакты из
**разных** пар, чтобы GPIO замыкался на землю лишь при нажатии. Внешний
резистор на кнопке не нужен: прошивка включает `INPUT_PULLUP`. Кнопку ИИ
не подключать ни к +5 В, ни к 3V3.

## Настройка после пайки

При внешнем блоке питания, отключённом от коробки, подключить только USB
компьютера. Загрузить окружение `screenless`, затем в последовательном
мониторе 115200 бод отправить **каждую строку отдельно**:

```text
ROOM 3
ASSIST PIN 17
```

После сообщений `ROOM SAVED` и `ASSIST PIN 17 SAVED` нажать `EN` для
перезапуска. В стартовом журнале должны быть `room=3` и `assistant button
GPIO17`. `STATUS` проверит идентификатор `HOUSE-3F-A-...`. `BUTTONS`
показывает большую и К1–К4; отдельная кнопка ИИ в строку `BUTTONS` не
входит. Для проверки звука есть `TEST SOUND` и `TEST MIC`.

В прошивке кнопка ИИ работает так: **удерживать — говорить, отпустить —
отправить вопрос**. Для ответа нужен работающий сетевой шлюз помощника
(`room 6`). Если он не запущен, код сообщает `ASSIST SKIPPED: assistant
offline`: исправная кнопка сама по себе не создаёт голосового помощника.
В текущей папке `intercom-5` программы шлюза нет; эту часть нужно будет
подключить и проверить отдельно.

Перед прозвонкой сопротивления выключить **и USB, и внешний блок**. Во
время прошивки не подавать 5 В одновременно от DC и USB. Эта схема
составлена по исходникам от 23.10.2026 и распиновке ранее собранных коробок;
пайка третьей коробки ещё не проверена на её физической плате.
