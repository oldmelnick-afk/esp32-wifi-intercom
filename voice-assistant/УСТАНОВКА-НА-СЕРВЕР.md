# Голосовой помощник переговорки: установка на сервер

Инструкция для ИИ-агента на сервере (Codex, Claude Code или любой другой) или
для человека. Выполни шаги по порядку и сообщи результат каждого. Папку целиком скопировали на сервер, например в
`C:\voice-assistant`. Работай из неё.

## Что это

Шлюз между ESP32-переговоркой и помощником. Коробки (192.168.0.201,
192.168.0.202 и др.) шлют голос по UDP на порт **42042**: 16 кГц, 16 бит, моно,
кадры по 20 мс. Шлюз объявляет себя «комнатой 6», распознаёт вопрос (Whisper,
локально), отвечает (шаблоны или GigaChat API Сбера), озвучивает ответ (Silero,
локально) и отправляет его обратно в коробку.

Файлы:
- `gateway.py` — сеть и очередь вопросов, точка входа;
- `assistant.py` — распознавание, ответы, озвучка;
- `config.json` — настройки (город, адрес коробки для таймера, модели, голос);
- `gigachat-key.txt` — ключ GigaChat (**секрет**, не показывать и не копировать в чаты);
- `models/whisper-medium`, `models/silero_v4_ru.pt` — модели, уже скачаны;
- `start_gateway.bat` — запуск с автоперезапуском;
- `install_service.ps1` — автозапуск при загрузке Windows и правило брандмауэра;
- `tools/fake_box.py` — проверка без коробок.

## Требования

- Сервер в той же домашней сети `192.168.0.x`, что и коробки (UDP-широковещание).
- Доступ в интернет: GigaChat (`*.devices.sberbank.ru`, работает **без VPN**),
  Open-Meteo, OpenStreetMap, OSRM.
- Корневой сертификат «Russian Trusted Root CA» (Минцифры) в хранилище Windows:
  без него GigaChat не подключится. Проверка — шаг 4.

## Шаги

1. **Python 3.11** (64-bit). Если `py -3.11 --version` не работает, установи
   Python 3.11 с python.org, отметив «Add to PATH» и «py launcher».
2. **Зависимости:**
   ```
   py -3.11 -m pip install -r requirements.txt
   py -3.11 -m pip install torch --index-url https://download.pytorch.org/whl/cpu
   ```
3. **Проверка частей:**
   ```
   py -3.11 -c "import assistant; print(assistant.speakable('Сейчас 6 градусов')); print(len(assistant.synthesize('Проверка')))"
   ```
   Ожидается текст «Сейчас шесть градусов» и число больше 10000.
4. **Проверка GigaChat:**
   ```
   py -3.11 -c "import assistant; print(assistant.Assistant().answer('Сколько будет два плюс два?'))"
   ```
   Ошибка SSL → установи сертификат Минцифры: https://www.gosuslugi.ru/crt
   («Russian Trusted Root CA», в «Доверенные корневые центры сертификации»
   локального компьютера), затем повтори.
5. **Видеокарта (необязательно).** Если есть NVIDIA (`nvidia-smi` работает),
   распознавание можно ускорить в ~8 раз:
   ```
   py -3.11 -m pip install nvidia-cublas-cu12 nvidia-cudnn-cu12==9.*
   ```
   `assistant.py` сам попробует GPU и при неудаче перейдёт на процессор. В
   журнале при первом вопросе видно время «речь N с».
6. **Остановить второй экземпляр.** Шлюз может работать только в **одном**
   месте сети. Попроси пользователя остановить шлюз на домашнем ПК (HOME-PC,
   192.168.0.85), прежде чем запускать здесь.
7. **Автозапуск** (PowerShell от администратора):
   ```
   powershell -ExecutionPolicy Bypass -File install_service.ps1
   ```
8. **Проверка работы.** Через ~20 секунд в `gateway.log` должны появиться строки
   `box room 1 at 192.168.0.201` и `assistant is room 6 ... waiting for boxes`.
   Проверка без коробок:
   ```
   py -3.11 tools\fake_box.py "Какое сегодня число?"
   ```
   Ожидается `first answer audio after N s`. (Шлюз отвечает на UDP-порт 42042
   адреса 127.0.0.2; если Windows не даёт привязаться к 127.0.0.2, пропусти
   этот шаг и проверь на настоящей коробке: три нажатия большой кнопки.)
9. **Постоянный адрес сервера** желателен (резерв DHCP в роутере TP-Link,
   «Расширенная → Сеть → DHCP-сервер»), но не обязателен: коробки находят
   помощника сами по пакетам HELLO.

## Если что-то не так

- В `gateway.log` нет `box room ...` → брандмауэр или другая подсеть: проверь
  правило «Intercom voice assistant (UDP 42042)» и что адрес сервера
  `192.168.0.x`.
- Коробка отвечает двумя низкими сигналами сразу после трёх нажатий → она не
  видит помощника: шлюз не запущен или порт закрыт.
- «Нет связи с помощником» → GigaChat недоступен: ключ, сертификат, интернет.
- Погода: Open-Meteo (серверы Hetzner) из домашней сети без VPN не открывается,
  поэтому при его недоступности прогноз берётся с api.met.no (Норвегия, без
  ключа). Последний удачный прогноз хранится в `weather-cache.json` (до 6 часов).
  При запуске шлюз пишет в журнал строки `net: ...` — какие сервисы доступны.
- Шлюз сам перезапускается через ~10 с после замены `assistant.py`,
  `gateway.py` или `config.json` (если не отвечает на вопрос в этот момент).
- Стоп и запуск вручную: `schtasks /End /TN IntercomVoiceAssistant`,
  `schtasks /Run /TN IntercomVoiceAssistant`.
